# Лендинг «Скуф-тур»

Одностраничник для выезда в горы на 2–3 дня из Краснодара. Черновик под
согласование с организатором: владелец пишет ему сам, и после согласия
черновик становится клиентским проектом.

Заодно это первая из семи новых работ для портфолио профиля FL.ru `kusaka63`.

## С чего начать

Читать `docs/superpowers/specs/2026-09-13-skuf-tur-landing-design.md` — там
всё решение целиком: структура из восьми экранов, тон, стек, проверки перед
сдачей и вопросы заказчику.

Дальше по порядку: план работ, вёрстка, предпросмотр со скриншотом, правки,
выкладка на GitHub Pages.

## Состояние на 13.09.2026

Страница свёрстана целиком и выложена: все восемь экранов, шрифт вшит,
заглушки под фото нарисованы кодом.

Живой адрес: https://pyhphhddb8-eng.github.io/skuf-tur/

Замерено на нём 13.09.2026: вес 44 319 байт, полная загрузка 0,36 с (медиана
трёх прогонов), запросов при открытии страницы — ровно один, сам документ.
Проверено там же: `http` уходит на `https` кодом 301, несуществующий адрес
отдаёт 404, файл на сервере совпадает с локальным побайтно, `noindex` на
месте, консоль пустая, на 360 px горизонтальной прокрутки нет.

В блоке отзывов стоит рабочая ссылка на объявление — оценка 5,0 проверяется
в один клик. Две кнопки «Написать в Телеграм» остаются заглушками до
согласования: адрес живёт в одной константе `TG_URL` в конце `index.html`.

**Осторожно с форматтером.** На этой машине после правки файла срабатывает
prettier и разворачивает всю разметку: вес вырастал с 44 до 53 КБ на одном
только переносе строк. Для страницы, которая продаётся лёгкостью, это
регрессия. Мелкие правки в `index.html` вносить так, чтобы форматтер не
трогал файл целиком, и после каждой сверять вес.

## Как проверить и посмотреть

    npm run check   # контраст по WCAG, прокрутка на 360px, alt, консоль
    npm run shot    # скриншоты 360 / 768 / 1280 в tools/shots/
    npm run og      # перерисовать og.png — превью ссылки для мессенджеров

`npm run check URL` проверяет живой адрес, а не локальный файл.

Папка `tools/` и `package.json` нужны только для проверок. Сама страница —
один файл `index.html` без зависимостей.

## Фактура

Взята из открытого объявления на Авито «Скуф тур — не напрягаемся»
(Краснодар, «Билеты и путешествия», № 7753483280, от 16 июля, 47 045
просмотров). Организатор — компания ORDA, контактное лицо Иван, рейтинг
продавца 5,0 из 5 при 29 отзывах.

Ничего сверх опубликованного не используется. Неизвестное вынесено в раздел
спеки «Вопросы заказчику», а не додумано.

## Решения, которые уже приняты

Целевое действие — написать в Телеграм, формы на странице нет. Поэтому нет и
сбора персональных данных, а с ним требований 152-ФЗ.

Тон — тёплый взрослый визуал, ирония живёт в заголовках. Мемное оформление
рассматривалось и отклонено: оно устаревает вместе с мемом, и по нему нельзя
оценить вёрстку, а работа должна показывать сетку, типографику и адаптив.

Стек — один самодостаточный HTML-файл без сборки и зависимостей.

Отзывы не копируются с Авито. На странице показывается проверяемая оценка со
ссылкой на источник, а места под цитаты остаются заглушками до разрешения
организатора.

Алкоголь из программы и скидка «альтушкам» в черновик не вошли — причины
и предлагаемые формулировки в конце спеки.

## Что нужно от заказчика

Цена за человека или за выезд, ближайшие открытые даты, что оплачивается
сверх цены, разрешение процитировать отзывы. Плюс фотографии гор, дома и бани:
места под них на странице размечены и подписаны.
